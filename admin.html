📥 Đồng bộ danh sách Gmail → Lớp

📋 Hướng dẫn:
1. Xuất danh sách Gmail từ Google Sheets / nhóm Zalo ra file Excel hoặc CSV
2. Chọn lớp muốn đồng bộ → Upload file → Hệ thống so sánh & liệt kê
3. Học sinh đã có tài khoản nhưng chưa có lớp này → thêm làm lớp phụ
4. Gmail chưa có tài khoản → bỏ qua (không tạo mới)
